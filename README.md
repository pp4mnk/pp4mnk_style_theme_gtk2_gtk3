Hi everyone!

I’ve included the individual files in case you’d like to browse or inspect them. For installation, download one of the two archives below. Each contains a ready-to-install `.pet` package for EasyOS and Puppy Linux.

- **`pp4mnk_style_pack1.tar.gz`** is the basic pack with the wallpaper and a few simple tweaks.
- **`pp4mnk_style_1.1.tar.gz`** is the full pack with everything listed below.

**What’s included in version 1.1**

- **PP4MNK-Light** and **PP4MNK-Dark** themes for GTK 2 and GTK 3, both included in the PET (the dark one has rox with incorrect colours, change it from rox OPTIONS).
- A **JWM theme** with a midnight-blue panel, a violet highlight for the active workspace, lavender window borders,
-  and a high-contrast clock.
- My original **1672 × 941 wallpaper**, bundled in the PET and also available as a standalone PNG.
- **15 drive icons** with lavender for unmounted drives, a cyan dot for mounted drives, and a padlock
- for protected drives.
- The icon installer **backs up your original icons** so you can restore them.
- An **optional Conky configuration**, previews, and guides in English and Spanish.

**How to get started**

Extract `pp4mnk_style_1.1.tar.gz` and open `pp4mnk_style-1.1.pet`. Then use the GTK theme, JWM theme,
and wallpaper selectors to apply the look you want.

To enable the drive icons in ROX-Filer, run `pp4mnk-style-icons apply`. The README explains how to restore your previous desktop appearance.
